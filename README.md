# 🖥️ NexusCycle

An ultra-lightweight multi-monitor wallpaper manager designed to be clean, minimal, and resource-friendly (**consuming less than 3 MB of RAM**).

Un administrador de fondos de pantalla para múltiples monitores diseñado para ser ultra-ligero, minimalista y eficiente (**consumiendo menos de 3 MB de RAM**).

---

## 🇺🇸 English Description

### ✨ Key Features
* 📂 **Massive Folder Reading:** Reads every single file inside your wallpaper folders and subfolders.
* 🖥️ **Independent Monitors:** Displays a completely different image on each screen simultaneously.
* 🔄 **Perfect Loop:** No image will ever repeat until the entire cycle of your folders is complete, restarting from zero automatically.
* 🪶 **Invisible Performance:** Runs quietly from your system tray using less than 3 MB of RAM.
